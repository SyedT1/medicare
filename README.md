# medicare
A complete, production-ready Hospital Management System (HMS) for managing patients, doctors, appointments, and medical records. Built with modern Java practices and strong security.

![Java](https://img.shields.io/badge/Java-21-orange) 
![Spring Boot](https://img.shields.io/badge/Spring%20Boot-3.3-brightgreen) 
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-16-blue)

## ✨ Features

- **Multi-Role Authentication** — Patient, Doctor, and Admin portals with JWT
- **Patient Management** — Registration, medical history, search
- **Doctor Management** — Profile, availability, schedule
- **Appointment System** — Real-time booking & status tracking
- **Bulk Data Import** — Spring Batch for patient records and medicine stock
- **Medical Records & Prescriptions** — Secure storage and retrieval
- **Role-Based Dashboards** — Personalized views for each user type
- **Advanced Search & Pagination** — Handles 100k+ records efficiently

## 🛠 Tech Stack

- **Backend**: Spring Boot 3, Spring Security, Spring Data JPA, Spring Batch
- **Database**: PostgreSQL
- **Tools**: Lombok, MapStruct, Swagger UI, Docker Compose, Maven
